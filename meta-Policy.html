Privacy Policy

Last Updated: July 27, 2026

1. Data Collection

This application does not collect, store, or retain any personal or non-personal user data.

The only data processed are messages sent by users to the Instagram page, which are transmitted through the official Meta API solely for the purpose of displaying and responding in real-time.

2. Use of Data

  • Messages are processed instantaneously for intelligent response generation.
  • No logs, history, or copies of messages are stored on our servers.
  • Data is never used for advertising, targeting, or profiling purposes.

3. Data Sharing

We do not share data with any third parties, except for:

  • Meta Platforms, Inc., through whose API messages are routed for processing. For more information on how Meta handles data, please review their Privacy Policy:
    https://www.facebook.com/privacy/policy

4. User Rights

Since no data is stored, requests for data deletion or modification are not applicable. However, users may stop the conversation or revoke the bot's access at any time directly through Instagram.
